# Admin workspace surface brief

## Mode

Operate. The visitor comes here to complete existing management tasks.

## Purpose

Support mentors and administrators managing the current TraderLab courses,
students, enrollments, banners, and notifications through an efficient,
minimal workspace.

## Success

Users can orient themselves from the left navigation, recognize the current
section, scan existing records and states, and find the existing actions
without changing how those actions work.

## Must remain untouched

Routes, authorization, API/data loading, forms, filters, pagination, actions,
role-based navigation, product copy, and all current capability limits.
